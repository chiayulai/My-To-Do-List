如何取得 Web API Key？

  1. 前往 Firebase 控制台專案設定
  2. 在「你的應用程式」中選擇 Web App（若無請按「新增應用程式」並命名為 My To-Do List）
  3. 複製 apiKey 與其他欄位貼至下方
  4. 確認在「Authentication」啟用「Google」供應商，並在「Firestore Database」建立資料庫。
